# 岗位描述样本：AI 应用开发实习生（大模型方向）

## 岗位职责
1. 参与公司 AI 应用产品的后端开发，基于大模型 API 实现智能问答、文档解析等功能；
2. 协助完成 Prompt 设计与调优，提升模型输出准确率；
3. 参与数据处理与评测脚本编写，整理标注数据集；
4. 与产品、算法同学协作，快速验证原型并迭代。

## 任职要求
1. 计算机相关专业本科及以上在读，大三或研二优先；
2. 熟悉 Java 或 Python 至少一门语言，具备基本的后端开发能力；
3. 了解 Spring Boot、MySQL 等常用技术，能够独立完成简单接口开发；
4. 对大模型（LLM）应用开发有浓厚兴趣，了解 Prompt 工程、RAG 等基本概念；
5. 每周可实习 4 天以上，连续实习 3 个月以上。

## 加分项
1. 有开源项目或个人技术博客；
2. 了解 Vue3 等前端框架，能完成简单页面开发；
3. 有 AI 相关竞赛或论文经历。
