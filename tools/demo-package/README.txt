  OfferPilot JD-简历匹配分析平台 —— Windows 离线演示包

一、项目简介
    OfferPilot 是基于大模型的 JD-简历匹配分析平台，围绕招聘场景提供
    完整的"JD 解析 -> 简历解析 -> 匹配评估 -> 改写建议 -> AI 面试官
    模拟面试"全流程演示。

二、功能列表
    1. JD 解析：自动提取职位要求、技能、经验年限、加分项等结构化信息。
    2. 简历解析：自动提取候选人教育背景、专业技能、证书资质、语言能力等。
    3. 匹配评估：多维加权评分（硬性技能 / 经验年限 / 项目成果 / 教育证书 /
       加分项与潜力），输出整体得分、等级、命中项、缺口项、风险提示。
    4. 改写建议：针对匹配缺口生成简历改写建议。
    5. AI 面试官：基于简历与 JD 生成面试问题，逐轮追问并输出评分与总结，
       支持完整面试过程快照回放。

★ 版本亮点（S6）
    1. AI 面试官模拟面试会话：基于简历与 JD 逐轮追问，形成完整面试会话，
       每轮追问输出评分与总结，可回放整场面试过程。
    2. 断网重放模式：内置离线快照（含 4 份 AI 面试快照），完全离线即可
       逐轮重放面试会话与匹配报告，无需联网、无需 API Key。
    3. JD-简历匹配分析：多维加权评分，输出整体得分、等级、命中项、缺口项
       与风险提示。
    4. 改写建议：针对匹配缺口自动生成简历改写建议（原文片段 / 改写后文本 /
       改写理由 / 关联缺口项）。
    5. 离线演示包：内置精简 Java 21 运行时与全部缓存快照，开箱即用，
       无需安装 JDK / Maven / Node.js，也无需联网与任何 API Key。

三、快速开始
    1. 将整个 OfferPilot-Demo 文件夹解压到本地磁盘（例如桌面或 D 盘）。
       注意：请先解压再运行，不要在压缩包内直接双击运行。
    2. 双击「启动演示.bat」。
    3. 等待约 10 至 30 秒，程序会自动打开浏览器访问 http://localhost:8083
      （若 8083 端口被占用，会自动改用 8085；再被占用则改用 8087，
        并在窗口中提示）。
    4. 演示结束后，双击「停止演示.bat」停止服务；直接关闭标题为
      「OfferPilot 演示服务」的窗口也能停止服务。

五、环境要求
    - 完全离线自包含：无需安装 JDK / Maven / Node.js，也无需联网。
    - 无需配置任何 API Key：分析/回放全部命中内置缓存与快照。

六、目录结构
    app\              后端单 jar（前端页面 + 后端 API 全栈一体）
    runtime\          内置精简 Java 21 运行时
    demo-cache\       离线结果缓存（16 条完整报告）
    demo-snapshots\   离线演示快照（12 份：SAMPLE + C01-C16 匹配 + interview 面试）

七、端口占用提示
    默认端口 8083；若被占用自动切换 8085 / 8087。
    若三个端口均被占用，请关闭相关程序后重新双击「启动演示.bat」。
    停止服务请使用「停止演示.bat」（会按进程匹配 offerpilot-backend.jar
    并停止，同时释放 8083/8085/8087 端口）。
