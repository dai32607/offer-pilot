## 1. 口播稿

### ① 开场

> OfferPilot 是一个 JD-简历匹配 Agent：输入岗位描述和简历，输出五维打分明细、命中点 / 缺口 / 风险，以及面试追问建议。后端 Spring Boot 3.2 + JDK21，前端 Vue3。

### ② 演示路径说明（必说）

> 为保证现场时延可控，匹配演示走**结果缓存 + 离线快照回放**路径；模拟面试演示走**面试快照离线回放**路径（见 §1.5）。两条路径均不依赖外部模型的实时网络响应。

### ③ 结果解读（唯一分数口径）

> 这份 JD 匹配结果总分 **88.1**，判定为**高度匹配**；五维评分已展开，命中 3 项、缺口 2 项、风险 2 项。三阶段耗时分别约 20.3s / 47.8s / 166.5s，模型组合为 deepseek-flash 抽取 + deepseek-v4-pro 推理，任务状态 SUCCEEDED。

### ④ 评测口径（主动交代，防被追问）

> 正式评测基线 = `eval/results/results_seed42_calib.jsonl`（固定种子 42 标识、25/25 全量重跑完成）。在 **6 组人工复核**（C01/C10/C13/C14/C18/C19）后：同档率 **23/25 = 92%**、Spearman **ρ ≈ 0.94**、**MAE ≈ 0.91**。仍需主动标注：评测集为 **25 组合成样本**，人工复核**进行中**（剩 19 组 PENDING），同档率/ρ/MAE 仅作内部优化参考，**不称准确率**。校准系数与阈值（α=0.7、β=0.3，阈值 81 / 47 / 20）在同一套评测集上拟合，样本量小，存在过拟合风险。

### ⑤ S6 模拟面试演示链路（新增）

> 演示顺序固定为：**进入面试面板 → 3 轮问答 → 自动总结 → 录制快照 → 离线重放**。全程演示链路能力，不把面试评分当评估结论。

| 步骤 | 操作 | 口播要点与数字口径 |
|---|---|---|
| 1. 进入面试面板 | 前端打开面试页（InterviewPanel.vue，路由 `/tasks/{taskNo}/interviews`），选择演示样本 **S6C01** 发起会话 | 面试官 Agent 基于 JD 解析 / 简历解析 / 匹配评估结果生成逐轮追问，最大轮数 3 |
| 2. 3 轮问答 | 逐轮由面试官出题、候选人作答，每轮返回评分 | 三轮聚焦维度与单轮分：① 硬性技能匹配 **78.0**；② 项目与成果相关度 **76.0**；③ 加分项与潜力 **78.0**；真实链路单轮时延约 63s / 160s / 142s（现场走快照回放，不展示等待） |
| 3. 自动总结 | 三轮结束后生成总结 Markdown（总体评价 / 分维度表现 / 薄弱环节 / 下一步准备建议） | 示例平均分 **77.3**（(78.0+76.0+78.0)/3），判定 **OK**；总结指出「后端与大模型实践未落地」等短板 |
| 4. 录制快照 | 会话完成后落盘为离线快照 | 快照 `backend\demo-snapshots\interview-S6C01.json`（2026-09-23 14:52 录制，3 轮、含事件序列）；/api/v1/replays 可列出 |
| 5. 离线重放 | 打开重放面板（ReplayPanel.vue），按快照重放事件时间线 | 重放按 **0.05× 速度**压缩事件节奏（单事件间隔上限 1200ms），**全程不调用外部模型 API**（事件带 offline_replay=true），断网可用 |

> 口径红线：平均分 77.3 是**单次示例会话**的数字，仅演示问答轮次、自动总结与快照回放能力，**不表述为面试评估准确率**，也不与匹配基线 92% 混用。

## 5. 边界声明（主动交代，别等被问）

1. 评测集为**合成样本**，非真实招聘数据。
2. 标签人工复核**进行中**：仅 C01/C10/C13/C14/C18/C19 六组完成，其余 19 组仍 PENDING。
3. 校准参数与评测标签**同源**，存在过拟合风险：改动标签 ≥3 组即需重跑校准。
4. 同档率、ρ、MAE 只作内部优化参考，**不得表述为准确率**。
5. C01 处于阈值临界带附近，单例结果不代表整体表现。
6. S6 面试演示为**单次示例会话**（平均分 77.3），仅演示轮次问答、自动总结与快照回放能力，**不构成对候选人水平的评估结论**。

## 6. 工程进度与已知缺口（2026-10-04 更新）

> 本节记录演示能力之外的工程进展与运行注意事项，供内部核对，不进口播稿。数字口径与 §1–§5 保持一致（88.1 / 92% / ρ0.94 / 77.3 等未变）。

### 6.1 S6 会话持久化与 60s 超时修复

- **会话文件持久化**：面试会话由 `InterviewSessionStore` 落盘到 `backend\data\session`（Jackson 原子写）；后端重启后自动恢复会话，`idSeq` 前移至最大 id。
- **边界**：仅面试会话落盘，`TaskStore`（分析任务/报告）为纯内存；重启后任务丢失，**只能对已恢复且处于 ONGOING 的会话继续 answer / finish，不能再开新任务**。
- **60s 超时缺陷已修复**：原 `answer()` 先 `setAnswer` 再 `runRound()`，异常不回滚导致「已作答无评分」且禁止重试（40009）。已修复为异常时回滚 `turn.answer=null / answeredAt=null` 并 `persist` 后重抛；**超时后该轮可重试，不再卡死**。黑洞端口 19999 实测 60s 超时触发回滚成功。
- **历史污染会话已清理**：旧版写入 `turn answered=True, score=null` 的污染会话（session-19/3/13/15/16）均已备份并删除，当前 `backend\data\session` 剩余 **20 个会话全部健康**，重启后正常恢复（恢复日志：`恢复 20 个会话（最新 id=25）`）。

### 6.2 前端新增能力（2026-10-04）

- **面试等待提示 UI**：InterviewPanel 新增 spinner + 进度条 + 已用时 + 预估剩余（est=90s），失败可重试；仅在真实链路展示，演示走快照回放路径不涉及。
- **暗色主题**：App.vue 支持跟随系统 / 亮 / 暗三态，基于 CSS 变量；ReportPanel / AgentTimeline / ReplayPanel 颜色已变量化。
- **ResizeObserver 良性报错过滤**：main.js 按白名单过滤 loop 类报错，不掩盖真实错误。
- **断线续传已实测通过**：App.vue 提供「模拟断线 / 重连（SSE 补齐）/ REST 补齐对账」三个按钮；EventSource 断开后自动重连并携带 Last-Event-ID，服务端只补发缺失 seq 的事件。浏览器实测：模拟断线后事件流停止（停在 seq 11），点击重连后事件补齐至 25 条、seq 1-25 连续无空洞、重连次数 0→1，任务 SUCCEEDED；REST 补齐对账与 SSE 事件集一致（补齐事件 0，无缺口无报错）。
- **报告骨架屏**：ReportPanel 加载态改为骨架屏（spinner + "报告生成中…（预计 20~160 秒）" + shimmer 骨架条），与面试等待 UI 风格统一（共用 CSS 变量、暗色兼容），加载完成后平滑过渡到真实报告内容。
- **上传页拖拽与文件预览**：App.vue 输入区升级为 drop-zone（JD / 简历各一个），支持拖拽或选择文本文件，选中后显示文件名 / 大小 / 类型并可移除，视觉层次与亮/暗色主题统一。
